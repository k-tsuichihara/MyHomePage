# メモツール

## 1. メモツールの概要

ブラウザ内にメモを保存するMyHomePageのツールです。公開導線は `tools/memo/memo.html` です。

## 2. 現行実装と利用できる機能

現行本体は [memo.html](memo.html)、[js/memo.js](js/memo.js)、[css/memo.css](css/memo.css) で構成され、JavaScriptとlocalStorageを使用します。

- タイトル・本文を入力してメモを追加し、一覧に表示する。
- メモを編集・更新する。編集のキャンセルができる。
- 確認後に個別削除・全削除する。
- 一覧に本文のプレビューと更新日時を表示する。

現行コードは保存時にタイトル・本文の前後空白を除去します。空タイトルは「無題」とし、空白のみの本文は保存しません。これは現行実装の説明であり、Ver1.1.0の入力契約とは区別します。

## 3. 現行実装の起動・利用方法

リポジトリルートをドキュメントルートとして静的HTTPサーバーで配信し、`/tools/memo/memo.html` にアクセスしてください。共通CSS・JavaScriptを相対参照するため、メモのディレクトリだけを切り出さずリポジトリ構成を維持します。

現行本体はHTMLからJavaScriptを直接読み込みます。この本体の利用にTypeScriptビルドやSupabase設定は必要ありません。特定のサーバー導入・ビルドコマンドはここでは規定しません。

## 4. 保存先と既存データの注意

保存先は利用中のブラウザのlocalStorageで、キーは `myhomepage.memo.items.v1` です。サーバーへのメモ保存や端末間同期は行いません。ブラウザ・プロファイル・オリジンが異なると保存領域も異なります。

既存キーを無断で削除・初期化しないでください。動作確認には既存データのない別のブラウザプロファイル等を使い、全削除操作には特に注意してください。本整理作業では画面操作・localStorage変更は実施していません。

## 5. Ver1.1.0の開発予定

Vanilla TypeScript化とSupabase連携を予定しています。認証、クラウド保存、タグ、ピン留め、ゴミ箱等の予定は統合仕様・画面設計を参照してください。現行本体に実装済みとは扱いません。

統合仕様ではローカルとSupabaseの保存領域は独立し、自動同期・転送・障害時フォールバックは行わない契約です。既存localStorageからの移行も正式仕様に従って別途実装・検証します。
