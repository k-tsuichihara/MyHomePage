# 読書記録用ツール

## 目的
読んだ本の記録をiPhoneやPCから入力できるようにしたうえで、記録を残すこと

## 使用技術

- React
- TypeScript
- Supabase
- Github Pages

## 主な機能
- 読んだ本の記録（本のタイトル・著者・読破日・メモ・感想・星1~5での評価）を行う
- 読んだ本の一覧表示
- タイトル検索
- 読破日での絞り込みや並び替え
- 月別読書冊数の表示
- 最後に読んだ日から何日たったかの表示
- 読んだ本の総冊数の表示
