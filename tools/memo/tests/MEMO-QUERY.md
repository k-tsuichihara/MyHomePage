# メモ一覧の読み取り契約・テスト方針

根拠：[review8統合仕様§5](../doc/v1.1.0/memo_v1_1_implementation_review8.md)、画面設計、ユーザー承認済みの検索・並び替え追加仕様。純粋関数のみを追加し、保存先・DOM・実ブラウザ・認証・実DBには接続しない。

## 入出力と検索

- queryMemosはunknownのMemoData全体を既存検証器で検証する。破損行を除外せず全体拒否する。load結果・pending入り保存形式・nullを空一覧として受理しない。呼出側は読込成功を確認し、MemoDataの3コレクションを渡す。
- optionsはview/text/selectedTagIds/sortのみ。省略時はnormal、空文字、空選択、updated-desc。未知項目・不正型・不正UUID・未知sortは拒否し、エラーへ検索値やデータ実値を含めない。
- textはECMAScript trim()で前後空白だけを除去し、単一文字列として扱う。内部空白・改行を分割しない。比較だけを双方のString.toLowerCase()で行い、locale依存変換・NFC/NFD正規化・全角半角変換・完全なUnicode case foldingは追加しない。保存値は変更しない。タグ名一意性のASCII限定キーとは別規則で、Ä/äは検索上同値になる。
- タイトル・本文・各関連タグ名に個別の部分一致を行う。複数フィールドを連結して架空の一致を作らない。空検索は文字条件なし。
- selectedTagIdsはUUID大小文字同値でOR、文字条件とはAND。同値重複選択は比較用集合でまとめ、最初の表記・選択順を保持する。削除済みIDは黙って解除せずmissingSelectedTagIdsとして返す。不在IDは一致対象なしだが、有効な別選択IDのOR一致は妨げない。
- タグ使用件数は既存countTagUsageが返す通常メモ全体の件数。queryMemosのresultCountは現在の検索・絞込結果件数であり、両者を置き換えない。

## 順序と詳細移動

- sortはupdated-desc（初期値）/updated-asc/created-desc/created-asc。通常一覧ではピンありを先にし、ピン同士はpinnedAt降順＋同値時ID昇順。選択sortはピンなし同士に適用する。
- ゴミ箱は選択sortにかかわらずdeletedAt降順＋同値時ID昇順で、ピン優先なし。effectiveSortに適用順序を返し、query.sortには通常一覧用の選択値を保持する。
- 日時は受理済みプロファイルのグレゴリオ暦・オフセット・最大6桁小数秒を整数マイクロ秒へ変換して比較する。Date.parse・ミリ秒丸め・原文字列の辞書順には頼らない。原文字列は保持する。
- 全ての同値時はUUIDを小文字の比較キーにしてID昇順で決め、配列の投入順に依存しない。
- 結果はquery、effectiveSort、items（memoと関連tags）、orderedIds、resultCount、missingSelectedTagIds。検証器が再構築した値を使い、元入力と可変参照を共有しない。文字列の表示用整形や本文の切詰めは行わない。
- getMemoNeighborsはこの結果のorderedIdsを受け、現在IDをUUID大小文字同値で検索する。positionは1始まり、両端のpreviousId/nextIdはnull。不在はnot-in-resultとして勝手に別のメモへ移動しない。不正UUID・同値重複ID列は拒否する。
- 絞込・並び順をこのID列で詳細へ渡せるが、画面のスクロール保持・離脱確認・現在メモ消失時の案内は後続UI工程の責務。

## テストと完了条件

| 観点 | 期待結果 |
|---|---|
| 日時 | 同一瞬間の異オフセット、小数秒1/6桁、マイクロ秒差、年0001/9999・閏年・世紀境界、前後日付境界 |
| 検索 | 3対象、Unicode小文字比較、空検索、前後空白、複数語未分割、複数フィールド横断の偽一致なし |
| 絞込 | タグOR＋文字AND、通常/ゴミ箱分離、不在選択ID通知、大小文字・重複選択 |
| ソート | 4モード、ピン優先・ピン日時、ゴミ箱削除日、ID同値判定、入力順の反転でも同じ結果 |
| 詳細 | 絞込後の前後ID、先頭/末尾/空/不在、UUID大小文字 |
| 安全性 | 不正な全体/関連/条件は拒否、凍結入力・後続入力変更からの独立、原文字列保持、失敗・pendingを空にしない |

既存542件を含む全Vitest、型チェック、差分チェック、セルフレビューを行う。完全削除、UI、JS生成・配信、実localStorage・実Web Locks・複数タブ・容量制限・実DBは未検証／対象外として後続へ引き継ぐ。専用の隔離環境・合成データ・成果物や生ログの公開除外・対象ブラウザを接続工程で承認後に準備する。正式仕様原本・AGENTS.md・全面実装／クラウド接続ゲートは変更・解除しない。
