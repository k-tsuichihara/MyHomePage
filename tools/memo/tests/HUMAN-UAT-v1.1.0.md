### UAT-01：PC/localで書く・明示保存・再読込

- **目的**：日本語入力から保存・閲覧まで、基本操作とPC表示を受け入れる。
- **前提条件**：承認されたlocal製品候補を起動。既存実利用データを使わない。
- **操作手順**：
  1. 一覧・保存先表示・共通ヘッダー／フッターを確認し、通常のPC利用幅と少し狭い幅へウィンドウを変更する。
  2. 「＋ 新規作成」でタイトル「UAT-日付 買い物」、本文にIMEで日本語の2行を入力し、変換確定・修正する。
  3. 「保存する」を押し、編集画面に留まり、ボタンの上付近に「保存しました」と表示され、内容を引き続き確認・編集できることを見る。
  4. 一覧へ戻り、カード左側のタイトル・本文プレビュー・更新日時の領域から同じ通常メモを開く。編集画面で保存内容を確認・継続編集できることを見る。右のケバブは別操作であることを確認し、「再読み込み」で保存内容を確認する。
  5. 「UAT-日付 読書」「UAT-日付 予定」も短い本文で作成・明示保存する。
- **期待結果**：成功確定時だけ編集画面の保存ボタン付近に「保存しました」を表示し、編集を継続できる。明示保存した内容を一覧・再読込後の編集画面で確認できる。単に前後メモがない場合はエラー風通知を出さない。カードは左側全体から編集を開け、hover背景色は付かない。保存・編集ボタンは新規作成と同じデザイン。日時は既存形式の前に「更新：」が付き読みやすい。ケバブの不要な「操作」文言・ボタン枠線・角丸がなく項目hoverは維持され、開閉でアイコンは動かず、外側クリックで閉じる。
- **Humanが見るポイント**：IMEの違和感、文字・ボタン・スクロールの視認性、保存前後の分かりやすさ。保存成功の案内がボタン付近に集約されていること、カードのマウスクリック時に黒枠が出ず、キーボードではフォーカスを見失わないこと。
- **結果**：FAIL
- **備考**：2026-11-19 Human報告。01-2／01-3／01-4のUX指摘で停止（下記U01-01〜14、13/14はPR #121後の追加指摘）。修正・AI Gate後もFAILを維持し、Humanが影響箇所を再確認してPASSと判断してから02へ進む。02/03等に影響するため02以降は未開始。全UATや01の無関係な確認まで最初からやり直さない。実施環境・時刻・対象buildの詳細は未報告。

## 結果更新・問題記録・再確認

- 状態は`NOT STARTED / PASS / FAIL / SKIP`の4種類。開始だけでPASSにしない。中断中はNOT STARTEDの備考に到達点を記す。期待結果を満たさない場合はFAILとする。
- 実施後は各ケースの結果・備考、一覧表、冒頭の件数を同じ更新で合わせる。`総数 = PASS + FAIL + SKIP + NOT STARTED`。残り実施数はNOT STARTED、未解決再確認数はFAILとして別々に見る。
- PASSはHumanの観測に基づく。新たなSKIPは理由・オーナー判断・引継ぎ先を必要とする。環境不足を自動的にSKIPへ変更しない。
