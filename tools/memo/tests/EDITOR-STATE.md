# ローカル編集・画面遷移の状態契約とテスト方針

根拠は[review8統合仕様§1・4・5](../doc/v1.1.0/memo_v1_1_implementation_review8.md)、[ローカル保存契約](LOCAL-SAVE.md)、[追加操作契約](LOCAL-OPERATIONS.md)、[一覧契約](MEMO-QUERY.md)、PR #10の承認事項。正式仕様・既存APIを変更せず、状態と判定だけを純粋関数として提供する。

## 編集と保存の境界

- 作成した状態・返却値は入力から独立させ、深く凍結する。状態はこのモジュールの生成関数から取得し、外部データを型キャストして注入しない。状態・ドラフト・要求はタブ内メモリ専用でログ／永続化対象にしない。
- ドラフトはtitle/body/tagIds。文字列は入力途中の空白・不正文字を含めそのまま保持する。タグ選択はUUID大小文字同値の集合として比較し、順序だけの変化は未保存にしない。重複選択・不正UUIDは拒否する。
- 未保存判定は整形前のドラフトとbaselineを比較する。保存開始時に既存normalizeMemoInputで検証・整形した要求と、整形前のrawDraftを独立して固定する。新規IDは呼出側から与え、自動再発行しない。
- beginSaveはローカルストアを呼ばず、submit判定と不変attemptを返す。呼出側が明示操作の結果としてattempt.requestを既存store.saveへ一度だけ渡す。requestIdはこの状態内でも再利用を拒否するが、ストア本来の使用済み登録はsave受付時（他の検証・ロックより前）のまま。状態側で書込前に検証拒否した要求はストアへ渡さない。
- 保存中の編集は許可し、二重保存・遷移は抑止。成功時はbaselineを送信時rawDraftに更新し、最新ドラフトは保持する。追加編集がなければclean、あればdirty。詳細状態に留まり、追加編集の保存完了を装わない。
- settleSaveは既存LocalSaveResultを受ける接続境界。savedだけを確定成功、rejected/not-attemptedを競合・拒否、unknown/unverifiedを結果不明とする。成功値も検証し、対象ID・内容・タグ・期待revisionとの不一致や不正応答は結果不明にする。例外は元例外を渡さずunknownへ変換して通知する。
- 操作ID・local保存先・画面sessionIdと進行中attemptが一致しない応答は無視。再利用済みoperationId/requestIdも拒否し、遅延／逆順応答を別操作へ流用しない。認証・cloud処理は実装しない。
- sessionIdは呼出側で画面セッションごとに新しく採番し、終了したセッションの識別子を再利用しない。save.kind=savedは送信した試行の成功だけを表し、現在のドラフトが保存済みかは必ずisDirtyも確認する。
- 結果不明のattempt（送信内容・requestId・rawDraft）はunresolvedに保持。自動再送なし。再保存は最新状態に結び付いた明示確認後、新operationId/requestIdだけで許可する。再保存の成功も以前の要求を解決済みにしない。新規の結果不明で同IDが既に保存されていれば、既存ストアが作成を拒否する。現在値から過去要求の成功を推測しない。
- 競合後のrevision更新や結果不明の解消を自動実行しない。非破壊再取得・比較・再編集の接続は後続工程。

## 確認・一覧の境界

- 離脱先は一覧／詳細／保存先切替要求／ログアウト相当要求。純粋な判定だけを返し、切替・認証・データ転送は実行しない。
- dirtyまたはunresolvedがあれば明示確認を要求。確認は状態オブジェクトそのものに結び付けた不変ticketとし、ドラフト変更（変更して元に戻す場合も）や保存結果反映後には古いticketを拒否する。別の確認表示では呼出側が保持する最新ticketだけを使う。
- キャンセルでは状態を維持。離脱許可も元ドラフトや不明要求を削除せず、返却されたretained状態として残す。呼出側は明示破棄確認済みの離脱でのみ画面セッションを終了できる。再起動後の復元保証はない。
- prepareLocalListはload結果を区別する。明示的emptyだけが正常な空データ。loadedはv2を再検証し、pendingや取得失敗・破損はblockedを返す。以前の一覧／ドラフトの破棄を指示しない。
- 一覧条件・ID順・不在選択タグ・scrollTopを独立して保持し、前後移動はPR #9のgetMemoNeighborsを利用。スクロール座標は有限の非負数。画面実装はDOMの読取／復元を別途行う。対象が結果外なら勝手に別メモへ置換しない。

## テスト計画・完了条件

| 観点 | 期待結果 |
|---|---|
| 保存成功 | 無編集はclean、送信後追加編集はdirty、整形前の空白は保持、revision更新 |
| 保存拒否／競合／不明 | ドラフト保持、不明attempt保持、再送なし、新IDで明示確認後のみ再保存 |
| 非同期 | 二重保存抑止、操作／保存先／session不一致・逆順・二重応答を無視 |
| 確認 | キャンセル、編集後・編集して復元後・保存後の旧ticket拒否、dirtyでない不明要求にも確認 |
| 一覧 | 検索・タグ・ソート・スクロール・前後順保持、emptyと失敗/pendingの分離 |
| 接続 | 合成メモリ保存先のLocalSaveResultをそのまま反映、requestIdのA案維持 |
| 非破壊性 | 凍結入力、入力の後続変更から独立、入力途中の不正値保持、原例外や実値をエラーへ出さない |

既存619件を含む全Vitestと型チェック、差分検査・セルフレビューを行う。DOM、実localStorage、実Web Locks、複数タブ、容量制限、ブラウザ離脱イベントは未検証。接続工程で隔離origin・合成データ・専用プロファイル・成果物公開除外・対象ブラウザを承認後に準備して検証する。完全削除・クラウド・認証・SQL変更・音声は対象外。正式仕様の未検証ゲートを解除しない。
