# ローカルJSONバックアップ出力契約・テスト方針

今回の承認：設計書§2.2の専用形式、UTF-8・BOMなし、生成JSONが10,485,760バイト以下。インポート上限・パーサーは未決定のまま。復元機能は実装しない。

## APIと安全境界

`createLocalBackup` は注入したgetItem・共通Web Locks・時計だけを保持する。書込能力・実localStorage取得・通信は持たない。共通ロック内で新旧キー取得、既存検証器で全体検証、正常v3確認、pending拒否、新旧生値の再照合を行う。取得後の独立値を使いロック解放後に直列化する。OS保存中はロックしない。

全通常／ゴミ箱メモ・全タグ・関連・deletedMemoIdsと原値・順序を保持。旧キー・migration/legacySnapshot・ドラフト・UI絞込・認証は除外する。空の正常v3は出力可能、キー不存在は出力しない。v2・pending・未知・破損・読取失敗・ロック異常・生値変化は全体停止。例外本文は返さない。

生成UTF-8バイト数が上限を超えたら切詰め・部分出力なし。追加の件数上限やインポート制限を導入しない。生成JSONを再解析し、内部の既存検証契約で値を再検証する。これは外部インポートパーサーではなく、重複キー検出等を決定するものではない。Blobの実バイト数・文字列一致も確認する。

検証UIは専用メモリ入口だけへ接続。公開HTML/旧JS・永続化入口は変更しない。準備中はボタン無効化と内部busyで二重起動を防ぐ。生本文をDOM・エラー・ログへ出さない。出力名は固定prefix＋UTC日時で、タイトルを含めない。

UIは範囲・平文の個人情報・除外内容・上限を事前表示する。非同期の準備・Blob検証後に通常のdownloadリンクを表示し、利用者の直接クリックで保存操作をブラウザへ渡す。準備だけではダウンロードせず、スクリプトから非同期後にclickを発行しない。リンク押下も「ダウンロード操作を受け付けました」とだけ通知し、保存開始・完了の確実な保証とはしない。

Blob URLはクリック後の固定1秒で解放せず、明示破棄・再作成・pagehideまで保持する。再作成は旧URLを解放して新しいスナップショットを取得し、pagehide後の古い非同期結果は表示しない。保持する準備済みURLは1つ。利用者には転送中の破棄・再作成・画面終了を避けるよう案内する。これらの操作が進行中のダウンロードへ与える影響やブラウザが保存完了を返さない限界は残る。固定待機時間を完了判定に使わない。

## 検証観点と実行

- Vitest：全配列・原値、空v3、metadata除外、書込能力なし、v2・pending・不正JSON・履歴衝突・不存在・読取例外・時計異常・ロック非対応／失敗・新旧値変化、10 MiB一致／1バイト超過・Unicode。
- Playwright：合成メモリv3のダウンロード内容、検索非依存、ドラフト非混入・保持、v2停止、禁止API非接続。準備だけではダウンロードしないこと、利用者のリンククリック、仮想時間で1秒経過後もURLを保持、明示破棄・再作成・pagehideイベントでの解放を検証。
- `npm run typecheck`、`npm test`、`npm run build:preview`、`npm run test:e2e`。既存単体・メモリE2Eも回帰する。

テストのJSONダウンロードはPlaywright管理の一時領域のみ。acceptDownloadsはこのspecだけ許可し、既存設定・永続API禁止ガードを緩めない。

## 保証範囲と残課題

取得時点のスナップショットであり、ダウンロード完了時の最新状態・ディスク耐久性・バックアップ真正性を保証しない。ロック非協調の同originコード・ABAは従来同様の限界。10 MiB判定は生成後で、巨大な既存保存値を解析する際のメモリ／時間の上限保証ではない。実機モバイル・OS保存ダイアログ・実ユーザー保存先は未検証。実保存先への接続・本番公開は別承認。

## 今回の検証結果

型チェック・Vitest 953件（既存937＋追加16）・メモリE2E 59件（既存55＋追加4）・検証UIビルドはPASS。最初のE2Eでは案内文を移行診断前の非表示DOMへ入れたため既存診断試験が失敗し、通常UI入場成功後だけに表示する修正後、全件再実行してPASSした。期待値は変更していない。

レビュー対応後：型チェック、Vitest 953件、メモリE2E 61件（追加のURL寿命・再作成／終了試験2件）、検証UIビルドはPASS。Chromiumの合成データ試験であり、Firefox/WebKit、実機モバイル、実際のOS保存ダイアログ・ディスク保存完了は未検証。元の指摘は再現済み不具合ではなく互換性リスクであり、全ブラウザで解消したという評価ではない。

今回の変更は独立した読取サービス・検証UI・合成fixtureへの接続に限定する。通常保存／移行／復旧・実ストレージアダプターは変更せず、所有プロファイル永続化・形式更新・切替E2Eは実施していない。実ストレージを読む許可を新たに広げたものではない。
