# 画面設計

## 画面一覧

|画面名|URL|目的|
|---|---|---|
|メイン画面|/|登録した本を一覧で見る|
|本登録画面|/books/new|読んだ本を登録する|
|本詳細画面|/books/:id|読んだ本の感想や詳細を見る/編集する|
|ログイン画面|/login|管理者としてログインする|

## メイン画面

### 目的
登録した本の情報や読破情報などを確認する。

### 表示項目 / 統計表示
- 総数（本棚 : 〇冊で表記）
- 本のタイトルと著者（表示は本の背表紙を意識して長方形の中に縦並びで）
　→　読みたい本リストとボタンで切り替える感じで。
- 各月ごとの読破冊数
- 感想を登録してから何日たったか

### 操作
- タイトル検索
- 読破日で絞込・並び替え
- 評価で絞込・並び替え
- 著者で絞込・並び替え
- 本詳細画面へ異動
- ログイン中のみ新規登録ボタンを表示

## 本登録画面

### 目的
読んだ本を新しく登録する。

### 入力項目
- タイトル
- 著者
- 読破日
- 評価
- 感想
- メモ
- （できれば）表紙

### 操作
- 保存
- キャンセル

### 本詳細画面

## 目的
登録した本の詳細・感想を確認する。

### 表示項目
- タイトル
- 著者
- 読破日
- 評価
- 感想
- メモ

## 操作
- 一覧へ戻る
- ログイン中のみ更新ボタンを表示
- ログイン中のみ削除ボタンを表示
